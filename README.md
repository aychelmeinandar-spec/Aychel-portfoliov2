## Jalankan secara lokal
1. Install Node.js versi LTS dari https://nodejs.org/.
2. Ekstrak ZIP dan buka terminal di folder `aychel-portfolio`.
3. Jalankan `npm install`.
4. Jalankan `npm run build` untuk memeriksa build produksi.
5. Jalankan `npm run dev`, lalu buka alamat lokal yang muncul (umumnya http://localhost:5173).

## Deploy ke Vercel
1. Buat repository baru di https://github.com/new.
2. Upload isi folder proyek ke repository (jangan upload `node_modules`).
3. Buka https://vercel.com/new dan import repository GitHub tersebut.
4. Pastikan pengaturan: Framework Preset `Vite`, Build Command `npm run build`, Output Directory `dist`, Install Command `npm install`.
5. Klik Deploy. Vercel akan menyediakan URL publik. Nama subdomain bergantung pada ketersediaan.
